## 🔧 Common Windows steps

If Windows blocks the file:

1. Right-click the downloaded file.
2. Select Properties.
3. Look for an Unblock box at the bottom.
4. Check Unblock if it appears.
5. Click Apply, then OK.
6. Open the file again.

If SmartScreen appears:

1. Select More info.
2. Select Run anyway if you trust the source.

If the app will not open:

- Restart your PC
- Download the file again
- Make sure the file finished downloading
- Run it as an administrator
- Check that your antivirus did not quarantine it

## 🧪 Basic troubleshooting

### The download does not start

- Refresh the page
- Try another browser
- Check your internet connection
- Disable a browser extension that blocks downloads

### The file opens and closes right away

- Run the file again as administrator
- Re-download the file
- Check for missing files in the same folder
- Make sure Windows did not block the app

### The app says a file is missing

- Keep all files from the download in the same folder
- Do not rename the app files
- Extract the full zip file before opening the app

### The screen looks too small

- Press Ctrl and + to zoom in
- Change your Windows display scale
- Use full screen if the app supports it
